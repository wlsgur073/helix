## actually-reachable outcomes

None. All seven advisories triage to `dev-toolchain-only` (2: esbuild, postcss) or
`bundled-unreachable` (5: `@hono/node-server`, `@modelcontextprotocol/sdk`, body-parser, fast-uri,

code path reachable from `src/server/index.ts`. No backlog entry is required this cycle.

## Limitations

- Reachability is source-reading over the bundle graph (metafile importer edges plus manual
  tracing of the shipped `bin/helix-mcp.mjs`), not a dynamic proof (no fuzzing, no runtime
  instrumentation). A future refactor that starts calling `elicitInput`, adds an HTTP transport,
  or introduces a `.url()`/URI-format field to a tool schema would need to re-run this triage.
- Dev-toolchain advisories (esbuild, postcss) are scoped to `npm ci` plus local build/test
  tooling; they do not ship in `bin/` and are not part of the runtime attack surface.
- This snapshot is point-in-time (2026-08-03). `npm audit` output changes as the advisory database
  and installed tree change; re-run Step 1 of the companion task brief before trusting these
  numbers on a later date.
