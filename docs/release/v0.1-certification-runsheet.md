```bash
python3 -c "import json; d=json.load(open('docs/release/v0.1-candidate-receipt.json')); print(d['payload']['candidateCommit'], d['payloadSha256'])"
```

**이 문서는 에세이가 아니라 실행 기록이다.** 각 단계에서 실행한 명령과 관측된 출력을 그 자리에
붙여 넣고, 대응하는 판정 행 ID를 적는다. 재구성한 출력을 관측으로 제시하지 않는다. 요약이라면
요약이라고 적는다.

**후보가 이동하면 이 파일 전체가 `STALE`이 된다.** 인증 도중 결함이 나오면 수정한 뒤
`v0.1-candidate-receipt.json`을 다시 발행하고 이 문서를 처음부터 다시 작성한다. 바뀐 번들
바이트를 가로질러 행을 이월하는 건전한 장부 기법은 없다. 값싼 자동 검사를 앞에, 비싼 수기
검사를 뒤에 배치한 이유가 그것이다.

**서식의 선례는 `c4-drills-2026-07.md`이다.** 후보 커밋, 3-sha 정체성, load path 해시, 콘솔
로그와 sha256 manifest, 새 프로세스에서의 관측을 남긴다. 그 문서가 `afc29c4`에 묶여 있었기
때문에 187 커밋 뒤에 만료를 계산할 수 있었다.
